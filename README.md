# 다이아리

팀을 만들고, 그 팀으로 야구 경기를 치르는 시뮬레이션입니다. 공 하나의 구종·구속·스트라이크 판정과, 맞았을 때의 방향·비거리·타구 속도가 경기 글에 남습니다.

공개 역사 구단 24개는 한국시리즈·플레이오프 공식 엔트리(또는 해당 시즌 주전 깊이표)에 맞춥니다. 엔트리에 없는 선수로 채우지 않습니다. 불펜과 마무리는 따로 나뉘어 있고, 투수 구속은 최고 시속입니다(시뮬에서는 평소 그보다 낮게 나갑니다). 히어로즈는 2008 우리·2009 서울·2014 넥센·2019 키움으로 나뉩니다. 2008 대한민국 국가대표는 베이징 올림픽 최종 24인이며, 능력치는 올림픽 본선 공식 누적 기록입니다. KBO 구단의 wRC+·sWAR는 공식 기본 기록에 없는 값이라 카운팅 기록으로 추정했습니다.

로그인은 없습니다. 혼자 쓰는 모드로, 열면 바로 팀·경기를 이용할 수 있습니다.

## 기록 저장 (브라우저)

경기·팀·업적은 **이 브라우저의 IndexedDB**에 남습니다. 서버를 끄거나 Cursor 세션이 끝나도, 같은 사이트 주소로 다시 열면 기록이 그대로입니다.

상시로 쓰려면 GitHub Pages 정적 사이트(아래)를 권장합니다. [virtual-uno](https://krartwide.github.io/virtual-uno/)와 같이 브라우저에만 의존합니다.

- Pages: https://krartwide.github.io/diari/
- 같은 브라우저·같은 주소를 쓰면 기록이 유지됩니다. 시크릿 창·다른 기기·캐시 삭제는 기록이 비워질 수 있습니다.

## 경기 모드

플레이 화면에서 고를 수 있습니다.

- **시리즈**: 단판, 2판 1선승, 3판 2선승, 5판 3선승, 7판 4선승, 와일드카드(홈 1승 / 원정 2승)
- **홈 어드밴티지**: 후공 타격·투수에 소폭 보정 (끄면 중립 구장)
- **이닝**: 9이닝 또는 7이닝(단축)
- **구장 배분**: 홈 고정, 교대, 한국시리즈형 2-3-2

## 실행 (개발)

```bash
cp .env.example .env
npm install
npx prisma migrate deploy
npm run dev
```

브라우저에서 http://127.0.0.1:43123 을 엽니다.

### 환경 변수 (개발 서버용)

개발 서버는 예전 SQLite API도 같이 띄웁니다. 로컬에 서버 기록이 있으면 처음 한 번 IndexedDB로 옮깁니다. 실제 플레이·저장은 브라우저입니다.

```bash
DATABASE_URL="file:../data/diari.db"
AUTH_SECRET=아무-문자열이나-있어도-됨
AUTH_TRUST_HOST=true
```

### GitHub Pages 정적 빌드

```bash
npm run build:pages
```

`out/` 이 `/diari` basePath 기준 정적 파일로 내보내집니다. `main` 푸시 시 `.github/workflows/pages.yml`이 https://krartwide.github.io/diari/ 로 배포합니다.

Docker·Railway 서버 배포는 선택 사항이며 [DEPLOY.md](./DEPLOY.md)를 보면 됩니다.

## 기록 입력

비율 기록은 소수점을 찍지 않아도 됩니다. 타율·출루율·장타율·OPS는 `285`가 `0.285`, ERA·WHIP은 `325`가 `3.25`, sWAR는 `635`가 `6.35`입니다. 이닝은 `188.2` 또는 `188 2/3`로 적을 수 있습니다.
