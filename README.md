# 다이아리

팀을 만들고, 그 팀으로 야구 경기를 치르는 시뮬레이션입니다. 공 하나의 구종·구속·스트라이크 판정과, 맞았을 때의 방향·비거리·타구 속도가 경기 글에 남습니다.

공개 역사 구단 21개는 그 시즌 가을야구에 쓸 수 있는 엔트리와 정규시즌 카운팅 기록입니다. 2014 키움 히어로즈는 당시 구단명 넥센 히어로즈의 시즌입니다. 2008 대한민국 국가대표는 베이징 올림픽 최종 24인 엔트리이며, 능력치는 그해 소속 리그 정규시즌(이승엽만 요미우리)입니다. wRC+와 sWAR는 공식 기본 기록에 없는 값이라 카운팅 기록으로 추정했습니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 http://127.0.0.1:43123 을 엽니다.

팀이 비공개면 이 브라우저에만 보입니다. 공개로 바꾸면 이 서버를 쓰는 다른 사람도 경기에 넣을 수 있습니다. 공개 역사 구단은 고치지 않고, 복제해서 내 팀으로 만듭니다.

비율 기록은 소수점을 찍지 않아도 됩니다. 타율·출루율·장타율·OPS는 `285`가 `0.285`, ERA·WHIP은 `325`가 `3.25`, sWAR는 `635`가 `6.35`입니다. 이닝은 `188.2` 또는 `188 2/3`로 적을 수 있습니다.
