# 다이아리

팀을 만들고, 그 팀으로 야구 경기를 치르는 시뮬레이션입니다. 공 하나의 구종·구속·스트라이크 판정과, 맞았을 때의 방향·비거리·타구 속도가 경기 글에 남습니다.

공개 역사 구단 23개는 한국시리즈·플레이오프 공식 엔트리(또는 해당 시즌 주전 깊이표)에 맞춥니다. 엔트리에 없는 선수로 채우지 않습니다. 불펜과 마무리는 따로 나뉘어 있고, 투수 구속은 최고 시속입니다(시뮬에서는 평소 그보다 낮게 나갑니다). 히어로즈는 2008 우리·2009 서울·2014 넥센으로 나뉩니다. 2008 대한민국 국가대표는 베이징 올림픽 최종 24인이며, 능력치는 올림픽 본선 공식 누적 기록입니다. KBO 구단의 wRC+·sWAR는 공식 기본 기록에 없는 값이라 카운팅 기록으로 추정했습니다.

로그인은 없습니다. 혼자 쓰는 모드로, 열면 바로 팀·경기를 이용할 수 있습니다.

## 실행

```bash
cp .env.example .env
npm install
npx prisma migrate deploy
npm run dev
```

브라우저에서 http://127.0.0.1:43123 을 엽니다.

### 계정

로그인 화면은 없습니다. 내부적으로 로컬 단독 사용자로 저장되며, 공개 역사 구단도 바로 고칠 수 있습니다.

```bash
DATABASE_URL="file:../data/diari.db"
AUTH_SECRET=아무-문자열이나-있어도-됨
AUTH_TRUST_HOST=true
```

브라우저는 **`http://127.0.0.1:43123`** 을 권장합니다.

### 상시 배포 (Cursor를 꺼도 유지)

Cursor 안의 서버는 세션이 끝나면 꺼집니다. Docker + Railway로 올리면 로그인 없이 바로 쓸 수 있습니다. 단계는 [DEPLOY.md](./DEPLOY.md)를 보면 됩니다.

로컬·단일 서버는 SQLite(`DATABASE_URL=file:...`)를 씁니다. 배포 이미지 기본값은 `file:/data/diari.db`이며, 볼륨을 `/data`에 붙이면 재배포 후에도 기록이 남습니다.

## 기록 입력

팀이 비공개면 본인 계정에만 보입니다. 공개로 바꾸면 이 서버를 쓰는 다른 사람도 경기에 넣을 수 있습니다. 일반 사용자는 공개 역사 구단을 고치지 않고 복제해서 내 팀으로 만듭니다. 사이트 운영자(`ADMIN_EMAILS`)는 공개 역사 구단 원본을 편집할 수 있습니다.

비율 기록은 소수점을 찍지 않아도 됩니다. 타율·출루율·장타율·OPS는 `285`가 `0.285`, ERA·WHIP은 `325`가 `3.25`, sWAR는 `635`가 `6.35`입니다. 이닝은 `188.2` 또는 `188 2/3`로 적을 수 있습니다.
